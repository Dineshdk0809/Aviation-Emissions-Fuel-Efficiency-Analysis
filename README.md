# Aviation-Emissions-Fuel-Efficiency-Analysis
End-to-end aviation emissions and fuel efficiency analysis using Power BI, including data quality assessment, data cleaning, emissions reporting, route analysis, aircraft efficiency evaluation, and executive-level recommendations.

## Project Overview

This project analyzes aviation operations, fuel consumption, and emissions data to evaluate fuel efficiency, identify emissions drivers, assess data quality, and support sustainability reporting.

The analysis was completed using Power BI and includes data cleaning, KPI development, dashboard creation, and executive-level reporting.

---

## Objectives

- Assess data quality and identify reporting risks.
- Analyze fuel consumption and CO₂ emissions.
- Evaluate aircraft-level fuel efficiency.
- Identify high-emission routes and operational patterns.
- Support sustainability and emissions reporting.

---

## Tools Used

- Power BI
- Power Query

- Excel

  ---

## Data Cleaning & Preparation

The dataset contained several data quality issues that were addressed before analysis:

- Removed 24 duplicate flight records.
- Removed 18 records with negative distance values.
- Removed 13 records with zero-distance values.
- Reviewed and documented 3,708 records with missing fuel data.
- Removed columns containing 100% null values.
- Standardized data types for dates, fuel, distance, passenger, and operational fields.

---

## Key Metrics

- Total Flights: ~15,000
- Total Fuel Burn: 159.38 Million kg
- Total CO₂ Emissions: 503.65 Million kg
- Average Load Factor: 78.81%

## Key Findings

- Data quality issues were identified and remediated prior to analysis.
- Total fuel consumption exceeded 159 million kg during the reporting period.
- Estimated CO₂ emissions exceeded 503 million kg.
- Medium-haul operations contributed the largest share of emissions.
- Emissions were concentrated across a limited number of routes and aircraft types.

---

## Recommendations

- Improve fuel data capture and completeness.
- Prioritize monitoring of high-emission routes and aircraft types.
- Implement automated data quality validation checks.
- Strengthen sustainability reporting processes.
